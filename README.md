# dotfile

This repo includes a bash script to install applications for development and copy my dot files to any new machine or freshly installed OS (currently Ubuntu)

## System Requirements

- Ubuntu (24.04, 24.10, 25.05, 26.04)
- Fedora (44)
- macOS (Apple Silicon + Intel, Sequoia 15+)

## Installation

Run [install.sh](install.sh) on Linux, [install.mac.sh](install.mac.sh) on macOS

## Guide to add new apps/sources

Read [GUIDE.md](GUIDE.md) to follow the guidelines used to update the script.
